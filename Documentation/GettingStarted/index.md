# Getting Started

To use Cratis Lens with an Arc application on your machine, follow Local Development, then Tenants and Users. You do not need to change Lens source or publish a release for this route.

- [Local Development](LocalDevelopment/index.md) — Build and load Lens, then open its popup on your application.
- [Tenants and Users](TenantsAndUsers/index.md) — Continue with the roster and context-selection workflow.
- [Build and Side Load in Chrome](BuildAndSideLoadInChrome/index.md) — Use this shorter procedure if you only need to build and load the extension.
- [Publishing Setup](Publishing/index.md) — Release-maintainer setup, not part of local application development.
