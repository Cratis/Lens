title: "Cratis Lens: inspect Arc commands and queries"
description: Cratis Lens is a Chrome extension that lists the commands and queries a running Arc application exposes, so you can inspect them while developing.
---

Cratis Lens is a browser extension for exploring the commands and queries exposed by a running Cratis Arc application during development.

Follow [Getting Started](GettingStarted/index.md), starting with [Local Development](GettingStarted/LocalDevelopment/index.md), to build and load Lens in Chrome, then open its popup on your application's page. You need a running Arc application; the local-development guide covers the build prerequisites.

When Lens recognizes the active tab as an Arc application, the Commands and Queries views become available. If they remain disabled, check that your application's page is active and click the popup's Arc detection status to retry.
